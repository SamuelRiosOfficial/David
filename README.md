# DAVID — El pastor, el rey, el amado de Dios

Videojuego bíblico 2D de plataformas desarrollado con **Godot 4** y **GDScript**.

## Dirección del proyecto

- Plataforma de desarrollo y pruebas iniciales: Windows 11.
- Orientación: horizontal (16:9).
- Enfoque: mobile-first, con controles táctiles previstos.
- Primer capítulo: **Un león y un oso**.
- Personaje principal: David adolescente, pastor de Belén.
- Mecánica principal: proteger cinco ovejas usando una honda.
- Enemigos principales: león y oso.
- Final del nivel: secuencia cinematográfica de video al entrar en casa, seguida de la pantalla de nivel completado.
